公差積み上げ計算

ワーストケース・統計（RSS）・補正RSS・モンテカルロで寸法チェーンを評価します。単位は mm と °。計算は端末内だけで行います。

寄与項目

入力の決まり

出力（すき間）＝ Σ 係数 × 項目の値。すき間を大きくする寸法は係数 ＋1、小さくする寸法は −1。てこ比や角度で効き方が変わる場合は、その比を係数に入れる（例：0.5、−1.2）。下の許容差は符号付きで入れる。

輪郭度など：公差値 t を ±t/2 のずれとして積む（面の輪郭度・平面度・直角度などを1方向のずれに換算）。

位置度：φt を ±t/2 として積む。Ⓜ を付けると、サイズの公差幅だけボーナス公差が加わる（最悪値は ±(t＋サイズ公差幅)/2）。統計計算ではサイズを公差の中央を中心とする正規分布、位置のずれを円内に一様（または正規）とみなす。

組付けの遊び：穴と軸（ボルト）のすき間の範囲で一様にずれるとみなす。最悪値は ±(最大の穴 − 最小の軸)/2。データム穴の Ⓜ によるデータムシフトも、データム穴とピン（最大実体境界）の寸法を入れれば同じ扱いになる。

ベクトル

入力の決まり

原点からベクトルを順につなぐ。角度は x 軸から反時計回り（°）。「前から」を選ぶと、前のベクトルの向きからの相対角度になる。

出力1は、目標点から見た終点の「測定方向」成分（すき間など）、出力2はそれと直交する成分（段差など）。感度係数は中心値のまわりで数値微分して求め、ワーストケースと統計はその線形近似で、モンテカルロは非線形のまま計算する。

出力の設定

規格（任意）

計算の設定

統計（±3σ）は、各項目の分布から求めた σ に感度係数を掛けて二乗和平方根をとったもの（全項目が正規分布なら従来の RSS と一致）。補正RSS は従来の RSS に 1.5 を掛けたもの（Bender）。モンテカルロは同じ入力なら同じ結果になるよう、乱数の種を固定している。

保存

入力内容はこの端末のブラウザに自動保存されます。
