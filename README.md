# stackup-calc

公差の積み上げ（スタックアップ）をブラウザだけで計算する Web アプリ。計算は端末内で完結し、データは外部に送信しない。

## できること

- **1次元**：寸法・輪郭度など・位置度（Ⓜ のボーナス公差を含む）・組付けの遊び（データムシフトを含む）を、感度係数を掛けて積み上げる
- **2次元ベクトルループ**：長さと角度のベクトルをつなぎ、目標点から見た終点の2方向成分（すき間・段差）を評価する。感度係数は数値微分で求める
- **計算方式**：ワーストケース、統計（各項目の分布から求めた σ の二乗和平方根、±3σ）、補正RSS（×1.5）、モンテカルロ（1万〜100万回、別スレッドで計算）
- **分布**：正規（±3σ）、一様、三角、Cpk 指定（平均のずれを含む）、実測（平均・σ）
- **積み上げブロック図**：すき間を広げる寸法・狭める寸法をブロックで並べ、すき間の内訳（ワーストケースの積み上げ）を表示する。部品をドラッグして置く・並べ替える・段を移す（係数の符号が反転）ことができる
- **図の直接操作**：ブロックの基準寸法、内訳・寄与率の公差、分布図の規格線、2次元のベクトルの先端をドラッグして値を変更できる
- **必要な公差の逆算**：目標（出力の Cpk、またはワーストケースで規格内）を満たすのに必要な公差を、全項目同率・1項目だけの2通りで求め、入力に反映できる
- **ケースの比較**：対策前・対策後などの入力を保存して、結果を並べて比べる
- **元に戻す・やり直す**（Ctrl+Z / Ctrl+Y）、**共有URL**（入力を URL の # 以降に圧縮して埋め込む）、**印刷用レポート**（PDF 保存用）

## 判定の基準

- 合格：全部品が公差内である前提が成り立ち、ワーストケースでも規格内
- 条件付き：統計（モンテカルロがあれば 0.135〜99.865%、なければ ±3σ）では規格内
- 不合格：統計でも規格外

実測分布で平均±3σが公差域をはみ出す項目や、Cpk が 1 未満の項目を含むときは「全部品が公差内」の前提が崩れるため、ワーストケースでの合格判定はしない。

## 構成

```
src/
  template.html   画面（HTML・CSS）
  engine.js       計算エンジン（画面に依存しない。Node・Web Worker からも読み込む）
  ui.js           画面の処理・図の描画・ドラッグ操作・逆算・ケース比較・共有URL・レポート
tools/build.py    src/ をまとめて docs/index.html を生成
tests/
  cases.js        例題をエンジンで計算して tests/out.json に書き出す
  verify.py       結果を Python で独立に計算し直して照合する（ワーストケースの総当たり、判定、逆算の境界を含む）
docs/index.html   ビルド結果（GitHub Pages の公開対象）
```

## ビルドとテスト

```
python tools/build.py
node tests/cases.js
python tests/verify.py
```
